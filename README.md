# 출첵 (CHULCHEK) — QR 실시간 출결 시스템

사내 행사·교육의 종이 서명 출결을 대체합니다. 관객이 폰으로 **15초마다 바뀌는 QR**을 찍고 **이름·사번**만 입력하면 출석되고, 운영자 대시보드의 **참여율이 실시간으로** 올라갑니다. 촬영 대리출석(만료 QR)·중복 출석을 자동 차단하고, 교육형은 퇴실 서명과 과제·퀴즈·만족도, 일반 행사형은 만족도 조사를 이어서 받습니다.

---

## 🔗 심사위원 확인 방법 (배포된 URL 기준)
1. **노트북/PC** 브라우저로 제출된 URL을 엽니다 → 운영자 대시보드 + 회전 QR이 나옵니다. (프로젝터에 띄우면 시연용)
2. **휴대폰 카메라**로 화면의 QR을 스캔 → 체크인 페이지가 열립니다.
3. **이름 + 사번**(예: `TEST-01`) 입력 → 출석하기.
4. 노트북 대시보드의 **출석 인원·참여율이 즉시** 올라가는 것을 확인.
5. (교육형) 상단에서 `퇴실 QR`로 바꿔 퇴실 → 과제·퀴즈·만족도. (일반형) 출석 직후 만족도 조사.
6. **만료 QR 테스트**: 예전 QR 사진을 나중에 찍으면 “만료된 QR” 거부 / **중복 테스트**: 같은 사번 두 번 → 거부.

> 여러 명이 서로 다른 폰으로 동시에 찍어도 한 대시보드에 실시간으로 모입니다.

---

## 🚀 배포 방법 — 심사위원이 열 수 있는 URL 만들기 (약 10분)

이 앱은 **정적 파일 1개(index.html)** + **Firebase 실시간 DB**로 동작합니다. 서버를 따로 켤 필요가 없어 어떤 무료 정적 호스팅에도 올릴 수 있고, URL은 **LTE·다른 와이파이 어디서나** 동작합니다.

### 1단계 — Firebase 연결 (약 5분)
`FIREBASE_셋업.md`를 따라 프로젝트를 만들고, `index.html` 상단의 `FIREBASE_CONFIG`에 설정값을 붙여넣습니다. (Realtime Database를 **테스트 모드**로 생성)

> 참고: Firebase 웹 `apiKey`는 비밀값이 아니며 공개돼도 됩니다(보안은 DB 규칙으로). 시연 후에는 DB를 초기화하거나 규칙을 잠그면 됩니다.

### 2단계 — 정적 호스팅에 올리기 (택 1)

**A. GitHub Pages — 영구 무료, ‘Git 저장소 + URL’ 동시 제출 (권장)**
1. https://github.com 가입 → **New repository** 생성(공개).
2. **Add file → Upload files**로 이 폴더의 파일들을 드래그해 커밋. *(CLI 불필요)*
3. **Settings → Pages → Deploy from a branch → main / (root) → Save.**
4. 몇 분 뒤 `https://<아이디>.github.io/<저장소>/` 주소가 생성 → **이 URL을 제출**. (저장소 주소도 함께 제출 가능)

**B. Tiiny.host — 60초, 파일 업로드만 (가장 빠름)**
1. https://tiiny.host 접속 → `index.html` 업로드 → 서브도메인 지정 → `your-name.tiiny.site` URL 즉시 생성.

**C. Netlify / Cloudflare Pages / Vercel** 등도 가능(정적 파일 배포).

---

## 🖥️ 대안 — 계정 없이 로컬 서버로 시연 (`chulchek-server.js`)
Firebase 없이, 발표자 노트북에서 `node chulchek-server.js` 한 줄로 실행하는 방식입니다. 관객이 **같은 Wi-Fi**에서 폰으로 QR을 찍으면 동작합니다. 자세한 방법은 `로컬서버_실행.md` 참고. (Node.js 필요)

- URL 제출이 필요하면 위 **정적 호스팅(A/B)** 방식을, 현장 로컬 시연이면 이 서버 방식을 쓰세요.

## 📁 파일 구성
| 파일 | 설명 |
|---|---|
| `index.html` | 제출용 웹앱 (Firebase 연결형, 정적 호스팅에 올리면 URL 완성) |
| `FIREBASE_셋업.md` | Firebase 프로젝트 생성·설정 붙여넣기 가이드 |
| `chulchek-server.js` | 계정 없이 로컬에서 `node`로 실행하는 대안 서버 |
| `로컬서버_실행.md` | 로컬 서버 실행 가이드 |

## 기술
바닐라 JS 단일 파일 · Firebase Realtime Database(무설치 백엔드) · 실시간 QR(qrcode-generator) · 시간 기반 회전 토큰(15초, 촬영 대리출석 차단) · SheetJS(엑셀 내보내기).
